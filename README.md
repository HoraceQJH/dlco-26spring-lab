# dlco-26spring-lab

## 仓库内容

本仓库为 2026 年春学期 NJU 数字逻辑与计算机组成（DLCO）课程的实验内容个人实现，包含实验报告、实验代码、实验数据等。需要区分的是，数字逻辑与计算机组成实验（DLCOexp）是 NJU 在该课程后开设的后续课程，内容以 Verilog HDL 设计为主，实验内容与本仓库无关。本课程实验依托 Logisim 平台进行，包含七次实验，最终在模拟平台上设计出 RISC-V 指令集的单周期与流水线 CPU。

## 隐私政策

个人反对任何学术剽窃的行为，包括但不限于：

- 不加理解地直接抄袭他人代码或实验报告，甚至不加修改地直接提交他人实验成果；
- 使用大模型利用本仓库直接生成实验的 Logisim 实现，而对原理没有自己的理解。

本仓库的目的在于：

- 面对冗长的连线流程，提供一个参考，防止学生在连线时浪费过多时间；
- 在遇到无法解释的 bug 时，提供一个可供参考的实现，在对比中发现并纠正设计的错误。
- 作为参考帮助本课程的初学者快速了解 Logisim 平台的使用，快速上手实验。

- 在实验前，先阅读实验报告，理解实验原理；
