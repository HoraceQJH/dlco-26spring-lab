\subsection{修改同步计数器电路设计，实现异步清零和异步置数的 4 位计数器，并说明该计数器的应用特性。}
\placeholder{
    使用D触发器的置位和清空功能即可。保存在文件 lab3.6.circ 中。

    应用特性：
    \begin{itemize}
        \item 异步清零：无需等待时钟周期，可以在紧急情况下立即复位计数器。
        \item 异步置数：无需等待时钟周期，可以在紧急情况下立即加载预设值。
    \end{itemize}
}
